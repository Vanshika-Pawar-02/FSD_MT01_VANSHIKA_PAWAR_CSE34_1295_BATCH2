# Library Book Management REST API

## Description
A REST API built using Node.js and Express.js to manage library books. Book records are stored in an in-memory array.

## Technologies Used
- Node.js
- Express.js
- Postman

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000/api/books`.


## Storage
All book records are stored in an in-memory array. Data resets when the server restarts.
